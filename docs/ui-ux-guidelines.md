# EndFi UI/UX 设计规范

> 来源声明：视觉设计参考《明日方舟：终末地》；文档内容由 AI 模型辅助整理与编写。

版本：0.1 · 基础：[Design Token](design-tokens.md)。

适用于通用 Web 工具、管理和内容界面。视觉目标是明确的位置感、清晰的信息层级和克制的工业气质，视觉原则与基础值由 Design Token 规范统一定义。本文定义页面布局、组件与组合模式的设计和交互合同，覆盖键盘操作、响应式、校验、加载和错误恢复。

## 1. 页面与交互基础

### 1.1 信息层级

页面标题 → 区块标题 → 正文 → 辅助说明 → 装饰编号。标题按语义结构组织，视觉字号不决定 HTML 层级。正文默认 `type.body`，辅助说明用 `type.caption`，控件用 `type.label`。compact 不缩小文字。

每个任务区最多一个主按钮。黄色表达“主要操作 / 当前选择”，不填满所有标题、标签和卡片。危险操作使用红色变体；其他动作使用 secondary 或无填充文字按钮。页面链接使用 teal 且带下划线。

必要信息不放入 12px 装饰编号。长中文允许换行，英文标识符允许在安全位置折行；截断项必须提供完整内容的可访问路径，不能只靠 hover tooltip。输入错误、操作名称、数值及单位不得省略。

### 1.2 布局与响应式

| 视口范围 | 页面布局 | 默认调整 |
| --- | --- | --- |
| 小于 640px | 单栏，左右 `layout.gutter.narrow` | 页标题用 panel 字体；工具栏换行；表单标签在上；弹窗宽度受视口约束 |
| 640–959px | 可用两栏卡片，左右 `layout.gutter.medium` | 主从视图仍使用列表 / 详情切换；筛选可收纳进抽屉 |
| 960–1279px | 可常驻 240px 侧栏，左右 medium | 主内容 `min-width: 0`；列表与详情独立组织 |
| 至少 1280px | 宽屏布局，左右 `layout.gutter.wide` | 内容最大 `layout.content.max`，居中；不无限拉宽正文 |

卡片网格采用最小期望宽度 `layout.grid.minCard`，实际容器不足时单栏；不能因侧栏导致内容横向溢出。页面竖向滚动，数据表可在自己的区域横向滚动。不得缩小整个页面来适配窄屏。

comfortable 的控件最小高度 40px，compact 为 32px；带多行文字的控件自然增长。图标按钮为正方形，触控模式至少 44px 点击宽高；控件视觉为 32/40px 时通过容器扩展命中区域，扩展区域不可与邻项重叠。可见 20px 的 checkbox / radio 通过整个标签行提供点击区域。

### 1.3 状态、输入与焦点

所有交互遵守 token 文档的状态覆盖合同。选中是数据状态，焦点是当前键盘位置；选择框、选中标签和错误边框均可同时具有独立焦点外环。

- Tab / Shift+Tab 按阅读顺序移动；组件内方向键按相应模式处理。按钮 Enter / Space 激活，链接 Enter 导航；禁用项不可激活。
- 图标操作有可访问名称；装饰图标不重复朗读标签。不可使用可点击的纯装饰文字代替按钮。
- 操作结束后焦点保持原位置，关闭模态回到触发器；触发器已移除时回到最近的逻辑操作入口。
- 消息通过合适的状态通知语义公布，不抢焦点；只有需要用户处理的模态才主动转移焦点。
- 表单采用可见标签与帮助文本，失焦或提交时校验；首次输入时不逐字报错。错误出现后，在更正输入时重新检查。提交失败保留用户输入。
- loading 使用可聚焦但不可重复激活的操作，保持按钮宽度和标签，补充进度图标与“正在保存”等状态说明；不把加载简单变成原生 disabled 而丢失焦点。
- prefers-reduced-motion 对应 duration.none，移除位移、闪烁与旋转；加载改为静态图标加状态文字，功能和反馈保留。

## 2. 操作与表单组件

下表“状态”之外，每个可交互项均支持独立 focus-visible。只读允许查看、选择和复制值，不使用 disabled 配色隐藏信息。

| 组件 | 结构、尺寸与 token | 状态与行为 | 文本 / 窄屏规则 |
| --- | --- | --- | --- |
| Button | 可选 20px 图标 + 标签；高度 / 内边距 / 字体用 button 映射；primary / secondary / danger / text 四变体；lg 使用 size.control.lg | 三种填充变体按 action 状态；text 无填充、primary 文字、hover / pressed 用普通表面；Enter / Space；loading 禁止重复执行，保留标签；失败恢复操作并显示原因 | 标签不截断，可增加高度；窄屏操作区可换行或整行按钮；不以图标代替关键确认文字 |
| IconButton | 默认方形 density.control.height；图标 size.icon.md；普通 action.secondary，危害性用明确名称和危险提示 | 与按钮相同；必须有可访问名称；tooltip 是补充 | 触控命中至少 44px；危险确认使用文字按钮 |
| TextInput | 标签在上、输入区、帮助 / 错误说明；input 映射；文字 type.body；1px 边界 | hover 用 border.strong，focus 保留边界并叠加外环；error 用 invalidBorder 与错误文本；readonly / disabled 分开；提交时关联标签和错误 | 标签 / 错误换行；值可水平移动查看，不截断数据；至少占满所在单元格 |
| Search | TextInput + 搜索图标；有值时清除按钮；“搜索…”只是 placeholder，仍需标签 | Enter 或搜索按钮显式提交，不默认逐字请求；清除恢复未筛选结果；清除按钮有名称且不提交表单；加载和结果数在结果区公布 | 窄屏占工具栏整行；无结果不视作系统错误 |
| Textarea | TextInput 配色，body 字体；初始至少 3 行；上下 padding space.8；允许竖向调整 | 同输入；不得以 Enter 自动提交多行内容；字数限制必须由具体业务说明 | 满容器宽；随文字换行；达到业务长度限制时说明原因，不静默截断粘贴 |
| Select | 标签 + 当前值 + 展开图标；input 结构；弹出列表用 floating 映射 | 单选默认，优先原生 select；自定义时 Enter / Space / Alt+Down 打开，方向键移动，Enter 确认，Esc 取消并回焦点；未确认不修改值；输入文字匹配选项 | 选项可换行；选中值可增长高度；窄屏列表不超出视口；搜索型组合框不在 v0.1 范围 |
| Checkbox | 20px 方框 + 8px 间隔 + 标签；未选为 input 背景 / 边框；选中用 choice 映射 | Space 切换；checked 显示勾；mixed 显示横杠并标明部分选中；disabled 仍保留勾或横杠 | 点击整个标签行；长标签换行；勾不作为唯一可访问状态 |
| Radio | 20px 圆形 + 标签；未选为 input 映射，选中用 choice 映射与圆点 | 同名组一次只选一项；Tab 进入组当前项，方向键移动并选择；Space 选择；组有可见名称 | 纵向排列是窄屏默认；不能用 radio 表示可多选项 |
| Switch | 48×24px 胶囊轨道、20px 拇指、2px 内边距，switch 映射；标明“开 / 关”或等价状态 | 左关右开，on 用主操作边框；off 的轨道与拇指均补 strong 描边；Space 切换；异步保存时锁定操作、显示状态，失败回滚并说明 | 点击标签与开关区域；只用于立即生效的二元设置；需要提交的表单选项使用 checkbox |
| SegmentedControl | 2–5 个互斥选项；input 边界、默认表面；选择项用 selection 三元组；高度 density.control.height | 使用 radio-group 行为：方向键选择，Space 确认当前；focus 外环与选中内边框分开；禁用选项可读且跳过 | 标签不截断；容器放不下时改用 radio 或 select，不横向挤压；用于值选择，不替代页面导航 |
| Slider | 标签 + 数值 / 单位 + 4px 轨道 + 20px 拇指，slider / progress 映射；拇指补 primary.border；命中至少 44px | 方向键 ±step，Home / End 到边界，PageUp / Down ±10×step；min / max / step / 单位由业务明确，不自定业务范围；同时允许输入数值 | 不能只显示颜色位置；窄屏数值移到标签下一行；精确数值输入用 TextInput，可达边界时保持反馈 |

按钮、输入及选择控件必须预留 4px 焦点空间。表面 pressed 时普通按钮边框使用 `color.border.strong`，避免边界在较深背景中失去辨识度。选择项边框预留 2px 占位，不能选中时挤压文字。

**推荐表单示例**：字段标签“项目名称” → 输入值 → 帮助“用于列表与导出文件” → 错误“请输入项目名称”。“保存”是 primary，“取消”是 secondary；不采用无标签输入框配一排图标的形式。

| Card | 标题、内容、可选操作区；card 映射；内容 gap space.16 | 静态卡不添加 hover；主入口卡用明确链接；可选择卡片用 control 边界与 selection 状态，不将所有卡片当按钮 | 多行标题自然增长；嵌套操作有独立焦点，不能在 button 内嵌 button；图像与内容区分开 |
| List | 行标题、辅助文本、可选前图标与尾操作；paddingY / gap 用 density.row，行分隔 border.subtle | 正文 body，辅助 caption；交互行用 surface.hover / pressed；单选行用 selection；整行点击只对应一个明确动作 | 多行高度自适应；正文单行行高加两侧 padding，comfortable 至少约 50px、compact 约 42px；尾操作不遮挡内容 |
| Table | caption / 表头 / 数据 / 可选排序与选择；table 映射；数值右对齐、tabular；正文 body | 表头用 label；排序按钮说明字段与顺序；多选使用 checkbox，表头 mixed 表示部分选择；loading 保留表头与列宽；可选行用 selection | 长文本换行，标识符可查看全文；窄屏放入带名称的横向滚动区域，不把重要列直接隐藏；静态表不整体采用交互 grid 键盘模式 |
| Badge | 图标可选 + 短状态文字；pill，8px 横向 / 2px 纵向 padding，caption 字体 | 默认 neutral 表面 / secondary 文字；状态使用 feedback 三元组；纯信息不响应点击；可移除筛选标签使用独立命名的删除按钮 | 状态名称不截断；数量必须真实，不用颜色模拟稀有度 |
| InlineHint / Alert | 图标 + 标题 / 说明 + 可选动作；feedback padding / gap；feedback 三元组 | 信息或成功使用温和通知语义；阻塞错误即时公布；操作是明确按钮 / 链接，不整个提示可点击 | 长说明换行；输入错误就近展示，不用 toast 替代；有关闭按钮时状态重要性不能因关闭而丢失 |
| Progress | 标签、当前数值 / 总量、4px 轨道；progress 映射；成功后用 success.foreground | 确定进度公布数值；不确定进度显示“处理中”，不伪造百分比；失败改用错误消息并提供恢复动作 | 缩窄仍保留数值与单位；不依赖细轨道区分完成情况 |
| Skeleton | 模拟最终布局，skeleton 配色与 radius；默认静态 | skeleton 对辅助技术隐藏，容器宣布“加载中”；加载结束一次性替换内容；失败切换错误状态，不无限播放 | 对齐预期列宽与图片比例，不随机变化；不模拟可点击操作 |

**推荐信息示例**：“运行状态”徽标使用成功绿 + 勾图标 + “正常”；“当前分类”使用 selection 黄与当前项语义。两者不能交换含义。

## 4. 浮层、反馈与恢复

### 4.1 浮层组件

| 组件 | 结构、token 与尺寸 | 交互与关闭规则 | 窄屏与溢出 |
| --- | --- | --- | --- |
| Dialog | 标题 + 关闭按钮 + 正文 + 底部操作；dialog 映射；宽 sm=400px / md=560px；遮罩 scrim；overlay / modal 层级 | 打开先聚焦首个合理控件；危险确认先聚焦取消；长说明先聚焦标题；焦点限制在模态内，背景不可操作；Esc / 关闭 / 取消一致执行取消逻辑；默认不点遮罩关闭 | 宽度不超过视口减两侧 gutter；最大高度为可用视口减两侧 gutter；仅正文滚动，标题和操作可达；操作区可换行 |
| Drawer | 标题 + 关闭 + 正文 + 可选底部操作；dialog 配色 / 阴影；最大宽度400px；默认右侧，导航抽屉左侧 | 作为模态处理焦点与背景；关闭规则同 Dialog；筛选草稿取消时丢弃，应用时提交；不自动保存筛选草稿 | 宽度受视口约束；正文滚动；屏幕键盘出现时使用可见视口，操作不被遮挡 |
| DropdownMenu | 触发按钮 + 列表；floating 映射；最小宽为触发器宽；行高 density.control.height，内边距 space.4 | Enter / Space 打开，方向键 / Home / End 导航，Enter 执行，Esc 回触发器；禁用项可读但不执行；点击外侧取消；执行后关闭，失败反馈在操作相关位置 | 在视口内翻转或移位；内容过长时菜单内滚动；可换行菜单文字；模态内用 z.modalPopover |
| Tooltip | 短说明，floating 映射，caption；padding space.8；不放交互内容 | hover 或键盘 focus 触发，fast 时长后显示，Esc 关闭；保持可悬停；与触发器说明关联；关闭后本次 hover / focus 不重新打开 | 宽度不超过可用视口，长文本换行；关键帮助在页面内展示，触控用户无需 tooltip 才能完成任务 |
| Toast | 图标 + 标题 / 说明 + 可选关闭 / 动作；floating 外壳，状态图标用 feedback.foreground；最大宽 dialog.sm；z.toast | 不抢焦点；纯信息 / 成功默认8秒，hover / focus 暂停；含操作、错误或警告须手动关闭；最多3条可见，相同操作重复消息合并；错误恢复不能只靠短暂通知 | 宽度不超视口；桌面右下，窄屏底部 gutter；模态打开时放置于不挡操作的独立通知区域 |

同一时刻只打开一个模态。菜单或选择器可在模态内打开；不从抽屉再叠加确认弹窗，改在抽屉内切换确认区。存在未保存编辑时，关闭动作先在当前模态内显示“继续编辑 / 放弃修改”；loading 时保留模态与焦点，关闭暂不可用并说明“保存完成后可关闭”，操作必须提供可理解的失败恢复。

自定义浮层不以背景模糊作为必须特效。默认 enter 240ms、exit 160ms，仅不超过 8px 的位移配合透明度；减少动效时立即显示。发光、噪点和持续闪动不是状态提示。

### 4.2 空、错、加载状态

| 场景 | 表现 | 恢复 |
| --- | --- | --- |
| 首次无数据 | 区块标题 + “还没有项目” + 可执行主操作 | “创建项目”；不显示重试 |
| 筛选无结果 | 保留工具栏、条件与“没有匹配结果” | 清除筛选或修改条件；不清空整个页面 |
| 初次加载 | 保留页面框架，内容区静态 skeleton / “加载中” | 请求失败后转错误状态 |
| 更新或翻页加载 | 保留已有数据并说明“正在更新”，相关操作防重复 | 成功替换，失败保留旧数据并提示尚未更新 |
| 请求失败 | 错误图标 + 具体可理解的失败说明 | 重试；涉及表单时保留值，焦点保持在操作入口 |
| 权限不足 / 不可用操作 | 显示原因，不伪装成空列表 | 提供可行的返回入口；不默认创造申请权限流程 |
| 保存成功 | 局部成功消息 / toast，保留当前上下文 | 明确已保存；不强制跳转、不依赖消息后继续操作 |

加载期间不显示虚假的空状态或0条结果；只有数据返回成功才显示真实空结果。长时操作保留状态说明；超时与取消能力由业务明确，设计层不虚构进度或承诺完成时间。

## 5. 常用组合模式

### 5.1 设置面板

结构为区块标题 + 设置行。每行包含标签、可选说明与控件；背景 `color.surface.subtle`，分隔 `color.border.subtle`，上下间距 `density.row.paddingY`，左右内边距 `density.panel.padding`。宽屏标签在左、控件在右；小于640px 时控件移至标签下面，用 `space.8` 分隔。

即时设置使用 Switch / Slider，非即时设置使用表单值与统一保存。键盘焦点显示在具体可操作控件上，设置行不使用整行永久焦点边框。含链接或辅助按钮的行不包成一个巨大按钮。

**组合验收样例：通知设置**

| 部位 | token / 规则 | 验收状态 |
| --- | --- | --- |
| 页面 / 面板 / 标题 | canvas / surface.default / type.heading.section | light 与 dark 配对一致 |
| 行内容 | type.body + type.caption，density.row / panel | 两种密度下长说明都可换行 |
| “接收通知” | Switch，switch.onBackground / offBackground / thumb，轨道边界按 switch 合同 | 开 / 关 / disabled / saving / 保存失败回滚 |
| “提示音量” | Slider，slider.fill / thumb + 数值 TextInput | 0–100%，step=1；方向键、精确输入和窄屏都可用；此范围仅为样例业务 |
| 聚焦及说明 | color.focus.ring 外环；错误用 error.foreground + 说明 | 焦点不被设置行裁切，错误不是黄色提示 |

### 5.2 筛选列表

结构为标题 / 结果数 → 搜索与筛选工具栏 → 已应用条件 → 列表或表格 → 分页。工具栏按钮间距 `space.8`，模块间距 `density.layout.gap`；宽屏工具栏可固定，使用 `z.sticky` 与不透明 surface.default。

搜索 Enter 提交；筛选抽屉的“应用筛选”提交草稿，“取消”保留旧条件。筛选改变后返回第一页；行选择默认限定当前页，表头选择说明“选择本页”，翻页和重新筛选后清除选择并公布。全量跨页批处理不在首版默认行为中。

**组合验收样例：项目列表**

| 部位 | token / 规则 | 验收状态 |
| --- | --- | --- |
| 工具栏 | input 映射；“新建项目” button.primary；“筛选” button.secondary | 加载不重复请求，窄屏搜索整行 |
| 已应用条件 | badge 映射 + 命名清除按钮 | 条件可读；“清除全部”恢复默认 |
| 列表 | table.headerBackground / divider / density.row，普通 surface.default | 数值右对齐、长中文换行、窄屏表格独立滚动 |
| 行选择 | choice.checked 三元组 + selection 背景 / 前景 / 边框 | selected + focus 同时可见，hover 保持选中 |
| 加载 / 无结果 / 错误 | skeleton / info / error 语义 | 分别表达；更新失败保留旧结果与已应用条件 |

### 5.3 选择网格

选择网格由可选择卡片组成，每张卡片包含名称、可选图像与明确的选择状态。使用 `layout.grid.minCard`、`density.layout.gap`；图像可方形，名称为可读文字。所有卡片预留2px边框，未选用1px control 边界，选中用2px selection.border、selection.background和勾标记。

单选采用 radio-group 行为，多选采用独立 checkbox 行为；选择与确认分开，底部显示已选择项与 primary“确认”。预览区为补充，不作为阅读名称的唯一入口。窄屏预览排在网格后方，卡片名称可换行；图片加载失败仍保留名称和选择操作。禁用项说明原因。

### 5.4 主从布局

至少960px时240px列表在左，详情在右，间距 `density.layout.gap`；当前项使用 selection 三元组，右侧内容标题可定位。列表切换不会强制把焦点移到详情，提供“查看详情”或逻辑上可达的详情区域。

窄屏展示列表 / 详情两级视图；打开详情聚焦标题，返回时恢复原项焦点与列表滚动位置。列表筛选与数据状态保留。详情有未保存输入时，切换前就地提供继续编辑 / 放弃修改的确认，不直接丢失输入。

### 5.5 确认与危险操作

普通确认使用 primary；破坏性确认使用 danger，标题直接说明对象和动作，例如“删除项目‘北区计划’？”。说明后果，不只写“确定吗”。单项普通删除不默认要求输入项目名称；只有业务确立额外风险时才扩展确认形式。

**组合验收样例：删除项目**

| 部位 | token / 规则 | 验收状态 |
| --- | --- | --- |
| 遮罩 / 面板 | overlay.scrim / dialog.background / dialog.shadow，z.overlay / z.modal | dark / light 局部主题继承正确，背景不可交互 |
| 标题 / 说明 | type.heading.panel / type.body，text.primary / secondary | 项目名称完整显示，长中文换行 |
| “取消” / “删除项目” | button.secondary / button.danger 全变体，space.8 间隔 | 默认焦点在取消，两个操作均有外环 |
| 执行状态 | danger default 配色保留，静态或动态进度图标 + “正在删除”说明 | 焦点不丢失，禁止重复提交与中途关闭 |
| 错误 / 完成 | error 三元组内联错误；成功后关闭并回到列表合理入口 | 失败保留弹窗并可重试；成功后原项目入口已移除，焦点回列表标题或相邻项 |

## 6. 评审与后续实现验收

本交付以文档一致性与 token 配对为验收对象；浏览器交互尚无组件代码可运行。后续实现按以下场景验证，不能把文档检查当作已经通过实机交互测试。

| 检查组 | 必测场景 | 通过条件 |
| --- | --- | --- |
| 主题与密度 | 三个组合样例 × light / dark × comfortable / compact；局部 light 面板置于 dark 页面 | 配色完整，无硬编码跨主题文字；compact 不缩小文字；局部浮层继承正确 |
| 文本与视口 | 320、639、640、959、960、1279、1280、1440px；长中文标题、说明与英文标识符；200%字号 / 页面缩放 | 正文可读、页面无意外横滚，表格有自己的滚动区；控件高度增长；弹窗操作始终可达 |
| 键盘 | Tab / Shift+Tab、Enter / Space、方向键、Home / End、Esc；radio / tabs / select / menu / slider | 顺序清晰、焦点不裁切、selected + focus 并存；模态焦点限制与返回符合规范 |
| 状态 | hover、pressed、selected、disabled、readonly、loading、error、success、warning、info | 覆盖顺序符合 token 合同；禁用不执行、加载不重复；颜色之外有可读状态 |

v0.1 不定义日期选择器、树、富文本编辑器、复杂图表、搜索型组合框或跨页批量操作。后续增加组件或组合模式时，先补充语义、交互与验收规范，明确主题、密度、响应式及状态映射，再实现。
